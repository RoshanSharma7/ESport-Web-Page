# Esport Web Page

## Overview
The **Esport Web Page** is a dynamic and responsive website designed to showcase esports-related content. It was built using fundamental web technologies to provide an engaging user experience with a sleek and interactive interface.

## Features
- **Responsive Design**: Optimized for different screen sizes using CSS.
- **Interactive UI**: JavaScript-powered animations and dynamic elements.
- **Esports Theme**: Designed with a modern aesthetic to fit the gaming and esports industry.
- **Navigation Bar**: Easy-to-use menu for seamless navigation.
- **Custom Styling**: Fully customized CSS for an attractive and unique look.

## Technologies Used
- **HTML**: Structure and layout of the web page.
- **CSS**: Styling and responsiveness.
- **JavaScript**: Interactive elements and dynamic content.

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/RoshanSharma7/EsportWebPage.git
   ```
2. Navigate to the project directory:
   ```sh
   cd EsportWebPage
   ```
3. Open `index.html` in your preferred browser.
